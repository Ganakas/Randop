# Randop

Right-click an empty spot in a folder and pick a random item.

Windows 10 shows the menu immediately. Windows 11 shows it with Shift + right-click, or under Show more options. Nothing stays in the tray. Open the program once to turn the menu on.

## Download

The current build is [Randop.exe](https://github.com/Ganakas/Randop/releases/latest) on the releases page.

## Build

Rust and Node.js are required. Run `build.bat`. It writes `Randop.exe` next to itself. The first build compiles dependencies and takes a few minutes.
